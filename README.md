# 🇪🇸 Levantando España

**Pequeñas marcas españolas levantadas a pulso. Esta Navidad, regala a quien se lo curra.**

Detrás de cada una de estas marcas hay alguien que madruga, que se la juega y que fabrica, diseña o cocina aquí. Este directorio reúne marcas españolas emergentes para que tus regalos de estas Navidades (y de todo el año) acaben en buenas manos.

> ¿Conoces una marca que debería estar aquí? [Propónla](#-añade-una-marca) 👇

🌐 **Ver el catálogo con fotos: [levantando-espana.vercel.app](https://levantando-espana.vercel.app)**

## ➕ Añade una marca

1. **Lo más fácil:** usa el formulario «Proponer una marca» de la web, o abre un [issue "Nueva marca"](../../issues/new?template=nueva-marca.yml). Con el nombre y la web basta: la revisamos y, si encaja, la añadimos.
2. **Con un Pull Request:** sigue la [guía de contribución](CONTRIBUTING.md).

**Leyenda de precio:** `€` hasta 30 € · `€€` 30–80 € · `€€€` más de 80 €
