# 🇪🇸 Levantando España

**Pequeñas marcas españolas levantadas a pulso. Esta Navidad, regala a quien se lo curra.**

Detrás de cada una de estas marcas hay alguien que madruga, que se la juega y que fabrica, diseña o cocina aquí. Este directorio reúne marcas españolas emergentes para que tus regalos de estas Navidades (y de todo el año) acaben en buenas manos.

> 🙌 Primeras marcas recopiladas del [hilo de J. Mencía](https://x.com/joaquinmencia/status/2118954222398181804) en X.

## ➕ Añade una marca

Dos formas:

1. **Sin tocar código:** abre un [issue con la plantilla "Nueva marca"](../../issues/new?template=nueva-marca.yml).
2. **Con un Pull Request:** añade una fila en la categoría que toque siguiendo la [guía de contribución](CONTRIBUTING.md).

**Leyenda de precio:** `€` hasta 30 € · `€€` 30–80 € · `€€€` más de 80 €
